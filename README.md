# Telmux‑rs

> PCBA 板载传感器遥测多路网关，Rust 实现。采集板卡原始传感器数据，本地运算处理，对外提供 Redfish / SNMP / Modbus 多协议访问接口。

## Overview

**Telmux‑rs** 是部署在 Windows / Linux 主机上的遥测网关服务：
1. 通过 Modbus‑TCP / Modbus‑RTU 与远端 PCBA 通信，读取板卡原始寄存器数据（温度、电压、电流、风扇转速等传感器原始值）；
2. 在主机本地完成单位换算、滑动滤波、数学计算、阈值判断、统计聚合等业务处理；
3. 将处理完成的标准化指标，对外同时暴露 **Redfish、SNMP、Modbus** 多协议接口；
4. 上层管理平台、SCADA、机房运维系统可任选协议读取 PCBA 的传感器状态。

### 适用场景

- BMC / PCBA 板卡硬件状态监控
- 硬件传感器原始数据采集与预处理
- 多协议统一出口，对接数据中心管理、工业控制系统
- 替代多套独立协议服务，单进程统一管理全部传感器指标

### 协议能力 (待实现)
- [ ] **Redfish**：硬件传感器资源模型，支持 GET 读取温度、电压、转速等 metric
- [ ] **SNMP**：自定义 MIB，输出处理后遥测指标，支持 Trap 告警（可选）
- [ ] **Modbus TCP / RTU**：寄存器映射传感器指标，支持读保持寄存器、输入寄存器
- [ ] 内部：原始数据采集层、数据处理管道、指标存储、配置驱动

## Architecture

```
[PCBA Sensors]
       ↓（原始 raw 数据读取）
┌─────────────────────┐
│  Acquisition Layer  │ 传感器抽象采集层，统一封装各类硬件读取接口
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ Processing Pipeline │ 滤波、换算、计算、统计、阈值判断
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│    Metric Store     │ 处理后指标内存存储
└──────────┬──────────┘
           ↓
     ┌─────┴─────┬────────┐
     ▼           ▼        ▼
Redfish       SNMP     Modbus
(HTTP)       (UDP)   (TCP/RTU)
```

## Features

- 传感器硬件抽象层，便于接入新的板载传感器
- 可配置数据处理流水线：均值、滑动滤波、单位转换、超限判断
- 多协议并行对外服务，共享同一套处理后的传感器指标
- TOML/YAML 配置文件驱动，无需修改代码即可映射寄存器 / Redfish 资源 / SNMP OID
- 守护进程模式运行，适合板卡后台常驻服务
- 结构化日志输出，支持调试、告警事件日志
- 低资源开销，适配嵌入式、BMC 受限运行环境
